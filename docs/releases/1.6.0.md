Download **[planar-studio-1.6.0.zip](https://github.com/jonahsaunders/planar-studio/releases/download/v1.6.0/planar-studio-1.6.0.zip)** from the release assets.

This development release supports **KiCad 9.0.1 or newer** on Windows, macOS
and Linux. It includes the transformer improvements made since 1.3.0.

### Transformer workflow

- Follow Requirements → Candidates → Windings → Verify → Export, with undo/redo,
  automatic checkpoints, preset previews and revision-aware verification.
- Combine independent core and winding choices, parallel sections, multiple
  outputs, physical stack heights and TDK N87 ELP core assemblies.
- Search constrained designs, compare candidates at common operating points,
  check named load cases and tolerances, and review calculated repair previews.
- Inspect leakage, AC copper loss, interwinding capacitance and response estimates;
  compare prototype measurements and retain alternative calibration fits.
- Adjust terminal positions, map destination nets, preview board placement and
  export a coordinated build dossier.
- Use keyboard stage navigation, visible focus, adaptive layouts and accessible
  chart tables. See the [transformer guide](https://github.com/jonahsaunders/planar-studio/blob/v1.6.0/docs/transformer-design.md)
  for supported models and their limits.

### Planar flyback example

The separate [5 W flyback example](https://github.com/jonahsaunders/planar-studio/tree/v1.6.0/examples/planar-flyback-5w)
contains an editable KiCad 10 project for an 18–36 V DC to isolated 5 V / 1 A
converter, integral six-layer windings, manufacturing files, component and
layout audits, and complete 3D views. Its M3 mounting holes use 4.5 mm corner
insets for capacitor clearance. The example and its review ZIP are in the
repository, rather than the plugin installer.

The example is an **unbuilt engineering prototype**. Hardware performance,
safety-isolation certification and supplier acceptance are unverified. The
transformer application's linear sinusoidal and small-signal estimates do not
replace switching-converter simulation or physical testing.

### Install

1. Download **planar-studio-1.6.0.zip** and leave it zipped.
2. In KiCad's main Project Manager, open **Plugin and Content Manager**.
3. Select **Install from File**, choose the ZIP, and apply pending changes.
4. Restart KiCad, open the PCB Editor and allow the plugin environment to finish
   setting up before opening Planar Studio.

When replacing an existing installation, close Planar Studio and the PCB Editor,
uninstall it from the manager's **Installed** tab, and **Apply Pending Changes**
before installing this ZIP. Saved designs are stored separately; preserve the
settings folder. GitHub's **Source code** archives are not PCM installers.
