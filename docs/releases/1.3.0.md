Download **[planar-studio-1.3.0.zip](https://github.com/jonahsaunders/planar-studio/releases/download/v1.3.0/planar-studio-1.3.0.zip)** below.

This is the packaged development release of Planar Studio 1.3.0 for **KiCad
9.0.1 or newer**, with the Inductor, PCB motor, Filter, Antenna and Transformer
workspaces. It uses the restored application version retained on `main`.

### Install

1. Download **planar-studio-1.3.0.zip** and leave it zipped.
2. Open KiCad's main Project Manager, then **Plugin and Content Manager**.
3. Select **Install from File**, choose the ZIP, and apply any pending changes.
4. Restart KiCad. Open the PCB Editor and allow the plugin environment to finish
   setting up before opening Planar Studio.

If Planar Studio is already installed, close its window and the PCB Editor,
uninstall it from the manager's **Installed** tab, and **Apply Pending Changes**
before installing this ZIP. Saved designs are kept separately; preserve the
settings folder.

Choose **planar-studio-1.3.0.zip** from the release assets. GitHub's automatic
**Source code** archives are for development and are not PCM installers.
